# Friends WhatsApp Bot

A private friends-only WhatsApp fun bot.

## Current stage

The project starts safely with WhatsApp disabled.

### Local setup

```bash
npm install
npm start
```

Copy `.env.example` to `.env` before configuring environment variables.

## Planned features

- Fun chat commands
- AI chat
- Games
- XP and leaderboard
- Group utilities
- Custom friends-group features
- Configurable command prefix
- Cooldowns and anti-spam controls

## Security

Never commit `.env`, WhatsApp authentication data, QR codes, API keys, or session credentials.
